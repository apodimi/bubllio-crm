# Tasks και follow-ups

Τα tasks απαντούν στην καθημερινή ερώτηση: **ποια είναι η επόμενη ενέργεια, για
ποιον πελάτη και ποιος είναι υπεύθυνος;**

## Τι καταγράφουμε

Κάθε task συνδέεται υποχρεωτικά με μία εταιρεία και μπορεί επιπλέον να συνδεθεί
με συγκεκριμένη επαφή ή deal. Περιλαμβάνει:

- σύντομο τίτλο,
- τύπο ενέργειας: task, call, email ή meeting,
- υπεύθυνο από τα μέλη του workspace,
- ημερομηνία και ώρα ολοκλήρωσης,
- προτεραιότητα,
- προαιρετικό χρόνο υπενθύμισης,
- εσωτερικές σημειώσεις.

Οι επιλογές εταιρείας, επαφής, deal και υπευθύνου περιορίζονται στο ίδιο
workspace. Μία επαφή ή ένα deal πρέπει επίσης να ανήκει στην επιλεγμένη εταιρεία.

## Καθημερινή χρήση

Η σελίδα **Tasks** ανοίγει στα προσωπικά tasks της ημέρας. Από εκεί μπορούμε να
δούμε:

- όσα πρέπει να γίνουν σήμερα,
- όσα έρχονται αργότερα,
- όσα έχουν καθυστερήσει,
- όλα τα ανοικτά ή τα ολοκληρωμένα tasks,
- τα tasks όλης της ομάδας ή όσα δεν έχουν ακόμη υπεύθυνο.

Το checkbox ολοκληρώνει ένα task χωρίς να διαγράφει το ιστορικό του. Ένα
ολοκληρωμένο task μπορεί να ανοίξει ξανά. Το Overview εμφανίζει τις σημερινές
και καθυστερημένες προσωπικές ενέργειες, ενώ κάθε deal δείχνει το πρώτο ανοικτό
task του ως **Next action**.

## Τι σημαίνει overdue

Το overdue δεν αποθηκεύεται χειροκίνητα. Υπολογίζεται όταν η ώρα ολοκλήρωσης
έχει περάσει και το task παραμένει ανοικτό. Έτσι η ένδειξη δεν μπορεί να μείνει
λανθασμένη επειδή κάποιος ξέχασε να αλλάξει status.

## Υπενθυμίσεις

Ο χρόνος υπενθύμισης καταγράφεται και εμφανίζεται στο CRM. Η τρέχουσα έκδοση
δεν αποστέλλει ακόμη email ή browser notifications· αυτό απαιτεί αξιόπιστο
scheduler και ξεχωριστή ρύθμιση τρόπου ειδοποίησης.

## Δικαιώματα

Owners, administrators και members μπορούν να δημιουργούν, να επεξεργάζονται,
να ολοκληρώνουν και να ανοίγουν ξανά tasks. Viewers μπορούν να τα διαβάζουν,
αλλά όχι να τα αλλάζουν. Όλα τα endpoints εφαρμόζουν tenant isolation.
